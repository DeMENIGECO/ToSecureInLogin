# 📁 `src`

Questa cartella contiene il codice sorgente di **ToSecureInLogin (TSIL)** e degli strumenti sviluppati per estendere il suo ecosistema.

---

## 📂 Contenuto

| Cartella | Descrizione |
| --- | --- |
| [`tsil`](tsil/) | 🔐 Sistema principale di ToSecureInLogin |
| [`aarg`](aarg/) | 🛠️ Automatic Account Registration Generator, strumento per la gestione degli utenti TSIL |

---

## 💡 Informazioni

Ogni componente presente in questa cartella ha uno scopo specifico:

- `tsil` contiene il sistema di autenticazione principale.
- `aarg` contiene strumenti per semplificare la creazione degli utenti.

Questa struttura permette di mantenere TSIL organizzato e facilmente estendibile.
