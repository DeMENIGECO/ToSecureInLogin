# 🚀 Introduzione

Benvenuto nella documentazione di **ToSecureInLogin (TSIL)**.

ToSecureInLogin è un progetto che permette di realizzare sistemi di login in **HTML** e **JavaScript**, utilizzando un semplice file **JSON** per la gestione degli utenti.

L'obiettivo di TSIL è offrire una soluzione semplice, leggera e facile da comprendere, ideale per piccoli progetti, prototipi e scopi didattici.

---

## ✨ Funzionalità

- 🔑 Token monouso
- 👤 Accesso tramite codice utente
- 📄 Gestione utenti con file JSON
- ⚡ Facile da integrare
- 🛠️ Facile da personalizzare

## ⚠️ Importante

TSIL non è pensato per applicazioni che richiedono un elevato livello di sicurezza.

Poiché il sistema funziona principalmente lato client e utilizza file JSON, è consigliato utilizzarlo per:

- Progetti personali
- Dimostrazioni
- Prototipi
- Attività didattiche

Per ambienti di produzione è consigliato utilizzare un backend con database e un sistema di autenticazione dedicato.
