# 📦 Installazione

Questa guida spiega come installare **ToSecureInLogin (TSIL)**.

---

## 📋 Requisiti

Prima di iniziare assicurati di avere:

- Un browser web moderno
- Un editor di testo o un IDE
- Un server web locale (consigliato)

---

## 📥 Ottenere TSIL

Scarica TSIL dalla repository GitHub oppure dalla pagina delle release.

---

## 📁 Estrarre i file

Estrai l'archivio in una cartella del tuo progetto.

La struttura principale comprende:

- `login.html`
- `reg.html`
- `users.json`

---

## ⚙️ Configurazione iniziale

Per iniziare è sufficiente modificare il file `users.json` aggiungendo i tuoi utenti.

Successivamente puoi personalizzare `login.html` e `reg.html` in base alle esigenze del tuo progetto.

---

## ✅ Installazione completata

TSIL è ora pronto per essere utilizzato.

Continua con la guida **Configurazione utenti** per creare il tuo primo account.
